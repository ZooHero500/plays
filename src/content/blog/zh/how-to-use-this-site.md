这站叫 Plays。
收的是别人已经在跑的 Grok Bot 用法。
不是官方站。
也不是 prompt 货架。

每条都有来源链接。
没有来源的，我们不编一条假的。
点赞和阅读数没有，就不写。
假数字比没有更糟。
打开一条，先看给出处的那一行。
能点回去，这条才站得住。

你没装过，先看 [怎么安装](/blog/怎么安装)。
那篇只有一个目标：你有一个叫得出名字的 bot。
装的步骤只写在那儿，以及更短的站内说明。
玩法正文不再教你下载，也不再教你点验证码。
官方入门在 [Get started](https://docs.x.ai/grok-bot/get-started)。
资格、桌面端、第一次建 bot，以那页为准。

有了第一个 bot，不要把三十三条都建一遍。
挑一条你本周已经在做的活。
销售在翻名单，看外呼过夜。
马上要演示，看 Demo 自检。
一个人盯仓库，看 Ray 那条把 bot 当成 CTO。
见 [Turn Grok Bot Into Your CTO](https://x.com/RayFernando1337/status/2090195841822998888)。
本周没有的活，先别建。
空座位会自己找事做。

打开一条，先看给谁、做完是什么。
再按步骤做。
步骤从这条真正开始的地方写。
底下的提示词，有原文就标原文，没有就标改写自哪篇。
不要把提示词当成可以不看出处的咒语。
官方岗位的起步任务，在 [Use cases](https://docs.x.ai/grok-bot/use-cases) 里。
我们写成怎么做，不把文档再抄一遍。

分类是给人找路的。
编制：门口怎么站，队怎么编。
工程：仓库、复现、调查。
增长：外呼、投放、内容。
生活：早报、邮箱、晚饭、家修。
官方玩法：xAI 自己写过的岗位。
标签最多先看三个。
点进去还能再筛。

Eric 在发布日列过一百条亲见的用法。
那不是菜单。
先读原帖，再挑一条你本周有的。
见 [原帖](https://x.com/ericzakariasson/status/2087258914060664902)。
一次全点，编制会先炸。

已经会用的人，直接逛。
按分类筛。
按标签点。
官方文档和社区文章分开看。
社区那几条，有的来自 DEV.to，有的来自一篇公开 playbook，有的来自 botdirectory.ai。
目录站是别人整理过的岗位。
我们写成怎么做，不写成「复制这一段就走」。
Elie 自己的目录，也要求你先跑通端到端再送回去。

三篇短文帮你站到门口。
[什么是 Grok Bot](/blog/什么是-grok-bot) 讲它是队友，不是聊天窗。
[和其他 agent 差在哪](/blog/和其他-agent-差在哪) 讲它和 ChatGPT、Claude Code、Cursor agent 各管什么。
叠着也能用。
不是换掉一个。

再往里走，看编制和审批。
[怎么给 bot 起名字](/blog/怎么给-bot-起名字)。
[先建总助再加人](/blog/先建总助再加人)。
[密码别进聊天](/blog/密码别进聊天)。
这三篇比玩法条目更慢。
适合坐下来读完，再去点分类。

这站会继续收有来源的用法。
你自己跑通的，也能按出处写进来。
没有出处的，标成没有，不要装成帖子。
