Getting started

How to use Grok Bot

Sign in with your Cursor account, create one focused bot, run a safe first task, then connect only the plugins you need. This unofficial Plays guide is a practical path—not another prompt dump—with linked plays from public posts.

What “using Grok Bot” means

A Grok Bot is a persistent agent with its own cloud computer, plugins, and routines—not a one-shot chat. Start with one outcome. Official docs cover product capabilities; this page covers order of operations and where to copy a real play next. Unofficial — see About.

Before you start

Install and sign-in live on /install. Use the same Cursor account; plan limits follow official docs. Never paste passwords into chat. This page starts after install.

FAQ

How do I use Grok Bot for the first time?

Install, create one bot with one job, run a safe draft-only task, then add plugins. Copy a Crew play after that.

Do I need Cursor Ultra / SuperGrok?

Plan names and limits change—check official docs. This guide does not hard-code prices.

Should I create one bot or many?

Start with one. Split when outcomes collide (sales draft vs eng PR watcher).

When do I connect plugins vs use the browser computer?

Plugins for account-bound apps; computer/browser when there is no connector. Prefer the safer path.

What should stay behind approval?

Outbound mail, CRM stage changes, payments, production deploys—human approve by default.
